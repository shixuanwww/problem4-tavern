3. 难度等级


#### 等级 1：开⻔营业（PDF 第 22 页）

在桌⾯尺⼨下，聊天、切换会话与发送消息均应可⽤。主要操作能⽤键盘完成，焦点可⻅，输⼊框有
可识别的标签。（可以做做⼿机的适配，如果⿇烦可以不做，做了加分）
聊天功能⾄少包括：
- 新建、重命名、切换和删除会话。
- 展⽰⻆⾊开场⽩，发送⽤⼾消息，逐步展⽰ai的回复。
- 刷新后恢复已保存的会话、消息和状态。
- 导出、导⼊单个会话，明确区分覆盖与创建副本。
需要正确处理以下情况：
- 重试不重复插⼊同⼀条⽤⼾消息。
- 未完成的助⼿回复默认不进⼊后续上下⽂。
- ⽣成中切换会话，后续结果仍属于发起请求的会话。
- 刷新打断的⽣成应标为中断，不能永远停在“⽣成中”。

#### 等级 2：调配记忆——本题核⼼（PDF 第 22–24 页）

想必你会遇到这种问题，时候有时候觉得ai给出的某个回复不是那么优秀，但是⼜不想要新开⼀个对
话，那么我们怎么让这条消息可以⽅便快捷地隐藏起来，不传给ai呢？

##### 消息控制

聊天记录⾥既有⽤⼾发的消息，也有 AI 回复的消息。两种消息都要能编辑，并分别控制以下两件事：
- 界⾯隐藏：不想看这条消息时，可以把它折叠或从聊天列表中隐藏。提供“显⽰已隐藏消息”或类
似⼊⼝，⽅便找回。隐藏显⽰不改变发给 AI 的内容。
- 不进⼊上下⽂：不想让 AI 再读这条消息时，可以把它排除出后续请求。正⽂仍然保存，随时可以重
新加⼊上下⽂。
⽀持单条操作，也⽀持批量处理。例如，选中⼀段旧消息后⼀起排除，或按“⽤⼾消息 / AI 消息”筛
选，再批量隐藏或恢复。让⽤⼾能看出哪些消息只是没显⽰，哪些消息没有发给 AI。
删除是另⼀个操作，不要⽤删除代替隐藏或排除。
修改历史消息会影响后续请求，但不能改写已经发出的请求快照。⽣成期间修改设置，也只能影响下
⼀次请求。

##### 世界书

（世界书是什么，世界书就是在RP的时候需要提供的世界信息，但是如果全部添加可能会影响模型智
⼒，需要在适当的时候添加的条⽬的集合叫做世界书）类似下图这种
实现⼀个世界书编辑器，⽀持创建、编辑、删除、启停条⽬。每条⾄少包括稳定 ID、名称、关键词数
组、正⽂、启⽤状态、常驻状态和优先级。
本题采⽤以下规则：
1. 可以做到扫描最近 N 条消息，包含本次待发送的⽤⼾消息中的与收录进来的世界书匹配的关键词
2. 在单条消息正⽂内进⾏关键词包含匹配；任意关键词命中即可成为候选，不跨消息拼接匹配。
3. 已启⽤的常驻条⽬直接成为候选；禁⽤条⽬始终排除。
4. 核⼼版本不递归扫描世界书正⽂，也不扫描⻆⾊设定和提⽰词模块。
5. 候选按优先级从⾼到低处理。优先级相同时，按 ASCII ID 升序处理；同⼀条⽬最多插⼊⼀次。
例如，扫描深度是 3，就检查最近 3 条符合条件的消息；关键词如果只在更早的消息⾥出现时，不触发
该条⽬。
提供发送前预览，并保存发送后的请求快照。检查视图⾄少能回答：
- 实际发送了哪些内容，顺序是什么？
- 每部分来⾃哪条消息、哪个模块或哪个世界书条⽬？
- 哪个关键词、哪条消息触发了世界书？
- 某条内容为什么没有发送：禁⽤、未命中、未完成、关闭上下⽂，还是什么别的原因？
上下⽂过⻓提醒
对话越来越⻓时，给⽤⼾⼀个清楚的提醒。例如：待发送内容达到设置的 80% 时，提⽰“上下⽂快满
了，可以排除较早的消息”。
提醒⾄少显⽰当前⽤量、上限和可处理的消息⼊⼝。

新预设符合已有格式时，不修改业务代码即可使⽤。

##### 把消息里的简单标签显示成小界面
背景：有时候，光靠⽂字聊天还不够有代⼊感。你可能希望⾃⼰的 RP 更像⼀场游戏：⻆⾊有⽣命值、
剩余令咒、当前位置，也有此刻穿戴的⾐物（以及到底有没有穿）。这些信息既是⻆⾊设定的⼀部
分，也能帮助你看清当前的处境，决定接下来怎么⾏动。
有些内容还会随着剧情变化，或者需要根据数值算出结果，⽐如⽣命值降低后的状态提⽰、⾏动消耗
后的剩余资源。如果每次都把这些信息混在⼤段对话⾥，找起来会很⿇烦，也不容易看出发⽣了什么
变化。
因此，请把消息中的这类信息显⽰成直观的⼩界⾯：⽤状态栏展⽰数值和⻆⾊状态，⽤按钮呈现下⼀
步可以选择的⾏动。让⽤⼾既能读故事，也能⼀眼看清这条消息⾥的⻆⾊状态，并⽅便地作出选择。
下⾯是⽰例格式
```
saber正在破坏圣杯
<tavern-panel type="status">
{"hp":10,"令咒":3,"location":"柳洞寺"}
</tavern-panel>
<tavern-panel type="choices">
{"options":[{"label":"发动令咒","text":"saber⾃裁吧"}]}
</tavern-panel>
```

这段消息应该显⽰为：⼀段普通正⽂、⼀张显⽰⽣命值、令咒数量和地点的状态栏，以及⼀个“发动
令咒”按钮。点击按钮后，输⼊框中填⼊“saber⾃裁吧”，由⽤⼾决定是否发送。
上⾯的代码块只是题⽬⽰例，⻆⾊设定、状态数值和选项内容都可以按⾃⼰的喜好调整。
在实际聊天消息中，当这些标签直接出现在正⽂⾥时，应⽤应识别它们、读取其中的数据，并展⽰成
